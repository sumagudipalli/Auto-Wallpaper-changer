# 🌄 Auto Wallpaper Changer (Web-Based)

A dynamic and lightweight web-based project that automatically changes the background wallpaper of a webpage using **HTML**, **CSS**, and **JavaScript**. Ideal for personal dashboards, smart displays, kiosks, or any live UI needing a fresh, beautiful look on every load or interval.

---

## 📌 Features

- 🎨 Auto-changing background wallpapers at regular time intervals.
- 🔁 Supports multiple image formats (JPG, PNG, etc.).
- ⚡ Lightweight, no external libraries or frameworks required.
- 📱 Fully responsive design across devices.
- 🔧 Easy to customize (images, speed, styles).
- 🌐 Runs in any modern browser – no server required.

---

## 🚀 Technologies Used

| Technology   | Purpose                           |
|--------------|------------------------------------|
| HTML5        | Markup structure of the webpage    |
| CSS3         | Styling and layout                 |
| JavaScript   | Logic for image switching          |
